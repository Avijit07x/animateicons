# @animateicons/angular

## 0.2.0

- Added 330 Lucide icons to the `lucide` subpath, so there are now 1500 (999 Lucide and 501 Huge). The same set as `@animateicons/react` 0.13.0, for example `ArrowBigDown`, `MonitorCheck`, `MapPinPlus`, `CalendarSync` and `StarHalf`.
- Shields now tilt on their bottom tip like they took a hit, and `Database` and `DatabaseBackup` drop a small record into the open top, the same as in React.
- Requires `@animateicons/vanilla` 0.2.0. No API changes.

## 0.1.0

- First release. The standalone `AnimateIcons` component with signal inputs, and 1170 animated icons (669 Lucide and 501 Huge) as data from the `lucide` and `huge` subpaths.
- Supports Angular 20, 21 and 22, zoneless apps and zone.js apps, and renders the icon at rest on the server. Plays the same animations as `@animateicons/react`.
