# @animateicons/vanilla

## 0.2.0

- Added 330 Lucide icons, so there are now 1500 (999 Lucide and 501 Huge). The same set as `@animateicons/react` 0.13.0, for example `ArrowBigDown`, `MonitorCheck`, `MapPinPlus`, `CalendarSync` and `StarHalf`, in the `lucide` subpath and in `dist/cdn/lucide.js`.
- Shields now tilt on their bottom tip like they took a hit, and `Database` and `DatabaseBackup` drop a small record into the open top, the same as in React.
- The Lucide CDN script, which holds every Lucide icon, grows from about 69 kB to about 84 kB compressed. Importing single icons costs the same as before.
- No API changes.

## 0.1.0

- First release. 1170 animated icons (669 Lucide and 501 Huge) for plain JavaScript, with `createIcon`, the `<animate-icons>` custom element and a CDN script per library.
- Plays the same animations as `@animateicons/react`, generated from the same source.
