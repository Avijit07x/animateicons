# @animateicons/vue

## 0.1.0

- First release. 1170 animated icon components (669 Lucide and 501 Huge) for Vue 3.5 and newer and Nuxt, plus the generic `AnimateIcons` component.
- Renders the icon at rest on the server, exposes typed `startAnimation` and `stopAnimation` on refs, and plays the same animations as `@animateicons/react`.
