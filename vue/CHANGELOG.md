# @animateicons/vue

## 0.2.0

- Added 330 Lucide icon components, so there are now 1500 (999 Lucide and 501 Huge). The same set as `@animateicons/react` 0.13.0, for example `ArrowBigDownIcon`, `MonitorCheckIcon`, `MapPinPlusIcon`, `CalendarSyncIcon` and `StarHalfIcon`.
- Shields now tilt on their bottom tip like they took a hit, and `DatabaseIcon` and `DatabaseBackupIcon` drop a small record into the open top, the same as in React.
- Requires `@animateicons/vanilla` 0.2.0. No API changes.

## 0.1.0

- First release. 1170 animated icon components (669 Lucide and 501 Huge) for Vue 3.5 and newer and Nuxt, plus the generic `AnimateIcons` component.
- Renders the icon at rest on the server, exposes typed `startAnimation` and `stopAnimation` on refs, and plays the same animations as `@animateicons/react`.
