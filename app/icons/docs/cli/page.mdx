# animateicons CLI

The fastest way to copy icons into your project. Same result as the shadcn CLI, but a first-party command instead of a registry URL.

#### 1. Add an icon

<CodeBlock code={cliAddCode} lang="bash" title="Terminal" />

Prefer a short command? Install the CLI globally and an `animateicons` binary is added to your PATH:

<CodeBlock code={cliGlobalCode} lang="bash" title="Terminal" />

Icons land at `components/icons/<name>.tsx` (override with `--dir`). The CLI also prints the `motion` install command for your package manager.

<Callout type="note">
	Copied icons import `cn` from `@/lib/utils`. If your project isn't
	shadcn-based, pass `--with-utils` and the CLI scaffolds a minimal helper for
	you.
</Callout>

#### 2. Browse without leaving the terminal

<CodeBlock code={cliBrowseCode} lang="bash" title="Terminal" />

Or open the interactive dashboard to search, multi-select, and add icons live in your terminal:
