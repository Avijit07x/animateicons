## What every package shares

- The same {ICON_COUNTS.total} icons. Their motion is checked frame by frame against React in every framework.
- Icons play on hover out of the box and reset when the pointer leaves.
- The same options: `size`, `color`, `duration` (a speed multiplier) and `isAnimated`.
- `startAnimation()` and `stopAnimation()` to play an icon from your own code.
- The **Reduce Motion** setting is respected with no setup.
- `motion` comes inside every package, so there is nothing else to install.

</section>

## Icon names

Every icon has a name such as `bell-ring`, shown in the [gallery](/icons/lucide). React and Vue export a component named after it in PascalCase with `Icon` at the end. Angular and plain JS export the icon itself, without `Icon`.

<CodeBlock code={namesCode} lang="ts" title="Imports" />

Lucide icons come from the `lucide` subpath and Huge icons from `huge`, because a few names exist in both, such as `heart` and `copy`.

## Other ways to add icons

- The [shadcn CLI](/icons/docs/shadcn) and the [animateicons CLI](/icons/docs/cli) copy a React icon into your project as an editable file, instead of installing the package.
- The [MCP server](/icons/docs/mcp) lets an AI coding agent such as Claude Code or Cursor find icons and write the code for any of the four frameworks.
