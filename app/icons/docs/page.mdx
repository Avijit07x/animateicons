# Installation

Pick whichever path fits your setup. They all ship the same icons and the same API. The difference is whether you depend on the package or copy the source into your project.

## npm package

<Badge>Recommended</Badge> Best for most apps. One install, all

#### 1. Install the package

Use any package manager. `motion` is bundled.

<CommandBlock pkg="@animateicons/react" />

#### 2. Import an icon

Lucide and Huge are exposed as scoped subpaths because some icon names overlap (`HeartIcon`, `CopyIcon`, etc.).

<CodeBlock code={npmUsageCode} title="Example.tsx" />

<Callout type="tip">
	Icons animate on hover out of the box, no extra wiring. Pass `size`, `color`,
	or any prop to customize.
</Callout>

#### Next.js App Router

Import each icon from its own file. Importing from the main package loads every icon: 918 kB of client JavaScript, compared with 71 kB for one icon.

<CodeBlock code={nextImportCode} title="Example.tsx" />

The path is the icon's file name, so `BellRingIcon` becomes `bell-ring-icon`. These paths only work with ESM imports. If you use `require()`, import from the main package.

## Prefer to copy the source?

If you'd rather own the icon files instead of depending on the package, use the [shadcn CLI](/icons/docs/shadcn) or the first-party [animateicons CLI](/icons/docs/cli). Using an AI coding agent? The [MCP server](/icons/docs/mcp) lets it add icons for you.

Once icons are in your project, head to [Usage](/icons/docs/usage) for styling, the imperative API, and full types.
