# Huge brand icons

Brand logos that Hugeicons has and we do not ship yet. Use it like a roadmap batch: take the first group that is not done, follow [adding-huge-icons.md](./adding-huge-icons.md), then delete its table here and add it to the Done table in [huge-roadmap.md](./huge-roadmap.md).

Snapshot: 2026-10-02. We ship 69 brand icons (the `Brands` category in `data/huge-icons.json`). The free Hugeicons set (`@hugeicons/core-free-icons` 4.3.5) has 133 more. All of them are plain stroke icons, so they follow the normal Huge icon pattern.

## Rules

- Work top to bottom. AI, Apple, Google and Microsoft are done, so the next group is the first table below.
- Ship families whole. Add every style of a brand in the same batch, for example all three `typescript` styles or both `notion` styles.
- Use `Brands` plus one more category, as the existing brand icons do (for example `Brands,Social` or `Brands,Coding & development`).
- Our name is the Hugeicons name in kebab-case, with every digit split by a hyphen: `01` is `-0-1`, and `Office365` is `office-3-6-5`. The registry rejects other spellings.
- Check `data/huge-icons.json` first, then run the family check from [adding-huge-icons.md](./adding-huge-icons.md).
- Decide before adding the loose ones: `bash`, `zsh`, `sql`, `cpp`, `mcp-server` and `pokeball` are tools or symbols more than brands.
