# Contributor docs

These guides are for people who work on AnimateIcons itself: adding icons and planning what to build next. They are not usage docs, so if you only want to use the icons in a project you can skip this folder.

## Using the icons?

Start here instead:

- [Install, CLI, styling and API](https://animateicons.in/icons/docs)
- [MCP server](https://animateicons.in/icons/docs/mcp)
- [Browse the gallery](https://animateicons.in/icons/lucide)
- [`@animateicons/react` on npm](https://www.npmjs.com/package/@animateicons/react)

## Contributing an icon?

Read [CONTRIBUTING.md](../CONTRIBUTING.md) first for the general flow, then the guide for the library you are adding to.

| Guide                                              | What it covers                                                                               |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| [adding-lucide-icons.md](./adding-lucide-icons.md) | Adding icons to the Lucide library: where the shapes come from and how to find ones we lack. |
| [adding-huge-icons.md](./adding-huge-icons.md)     | Adding icons to the Huge library: the Hugeicons names, the shapes and the family check.      |
