# Security policy

## Supported versions

Security fixes are released for the latest version of each package:

| Package               | Supported      |
| --------------------- | -------------- |
| `@animateicons/react` | latest release |
| `animateicons` (CLI)  | latest release |
| `@animateicons/mcp`   | latest release |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately with GitHub's
[private vulnerability reporting](https://github.com/Avijit07x/animateicons/security/advisories/new).
Include the affected package and version, what an attacker could do, and steps
to reproduce.

You will get an acknowledgement as soon as possible. Once the issue is
confirmed, a fix is released and the report is credited, unless you prefer to
stay anonymous.
